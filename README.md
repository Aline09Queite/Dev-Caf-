☕ Cafeteria do Dev

Projeto desenvolvido durante as aulas do DevClub com o objetivo de praticar e aprimorar meus conhecimentos em HTML e CSS, explorando diferentes estilizações e recursos de construção de páginas web.

🚀 Sobre o projeto

O Cafeteria do Dev é uma página web inspirada em uma cafeteria, desenvolvida para colocar em prática conceitos de estruturação, estilização e organização de elementos utilizando HTML e CSS.

Durante o desenvolvimento, pratiquei diferentes formas de estilizar a página, trabalhando com cores, fontes, imagens, espaçamentos, posicionamento e organização dos elementos.

🛠️ Tecnologias utilizadas

* HTML5
* CSS3

📚 O que pratiquei

* Estruturação de páginas com HTML
* Estilização com CSS
* Organização e posicionamento de elementos
* Utilização de imagens
* Tipografia e fontes
* Cores, espaçamentos e tamanhos
* Criação de cards
* Construção de uma interface visualmente organizada

🎯 Objetivo

Este projeto faz parte da minha jornada de estudos em desenvolvimento web. A cada projeto, busco praticar os conteúdos aprendidos e transformar a teoria em algo funcional.

Ainda estou evoluindo e aprendendo cada vez mais, mas é muito gratificante poder olhar para cada projeto e perceber minha evolução. 🚀
